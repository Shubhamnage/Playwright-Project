# Test Plan: Test Automation Practice Website

## 1. Scope and inspection notes

- **Application:** [Automation Testing Practice](https://testautomationpractice.blogspot.com/)
- **Inspected:** 2026-10-29
- **Pages inspected:**
  - Home: `https://testautomationpractice.blogspot.com/`
  - PlaywrightPractice: `https://testautomationpractice.blogspot.com/p/playwrightpractice.html`
  - Hidden Elements & AJAX: `https://testautomationpractice.blogspot.com/p/gui-elements-ajax-hidden.html`
- The two practice pages reuse many homepage widgets, tables, footer sections, and navigation links. Scenarios for those shared widgets are grouped once under **Shared practice widgets**; run them against each page where the widget is present.
- This is a test plan only; no automation code is included. Page content, visible labels, element IDs, and table dimensions below reflect the pages as inspected. Do not treat example data or observed initial states as permanent fixtures.
- “Verify” expectations below mean the outcome is not established by static inspection and must be confirmed against the live site before treating it as a fixed assertion. Console errors were reported during page loads; their source and impact were not investigated.
- **Priorities:** P1 = core/high-value, P2 = important, P3 = lower risk or exploratory.
- **Automation suitability:** High = stable observable interaction; Medium = feasible but dynamic/external/ambiguous behavior needs controlled assertions; Investigate = confirm behavior or fixtures before committing an automated assertion.

### Observed section and control inventory

- **Home header/navigation:** site title and subtitle; Home, Udemy Courses, Online Trainings, Blog, and PlaywrightPractice links.
- **Home main content:** Data Entry Form (text fields, textarea, radio buttons, day checkboxes, country/color/animal selects, two text date pickers, start/end date controls, submit); single/multiple Upload Files controls; Static Web Table; Dynamic Web Table; Pagination Web Table.
- **Shared side widgets:** Tabs; START dynamic button; Simple Alert, Confirmation Alert, Prompt Alert; New Tab and Popup Windows; Point Me hover menu; Double Click fields/button; Drag and Drop source/target; Slider; SVG Elements; Scrolling DropDown; Labels And Links; Visitors.
- **PlaywrightPractice-specific content:** locator examples for getByRole, getByText, getByLabel, getByPlaceholder, getByAltText, getByTitle, and getByTestId; example buttons and form controls; shared uploads/tables/widgets.
- **Hidden Elements & AJAX-specific content:** two text inputs, two checkboxes, Toggle Input Box 2, Toggle Checkbox 2, and Load AJAX Content; shared uploads/tables/widgets.
- **Footer/shared content:** three Form Section blocks, each with a paragraph and Submit button; Footer Links including Home, Hidden Elements & AJAX, and Download Files; ShadowDOM/Youtube content; Posts (Atom), visitor section, and Blogger/theme attribution links.
- The site includes outbound links (course/training/blog and attribution links) and pages outside this plan such as Download Files. They are inventoried but not explored as separate application pages.

## 3. Reusable scenarios and Page Object Model candidates

### Reusable test flows

- **Page shell/navigation:** verify page title, primary navigation, footer links, current URL, and return-to-Home behavior on all three inspected pages.
- **Widget smoke flow:** run common widget visibility/locator checks on each page that renders the widget; keep action-heavy tests scoped to one canonical page unless page parity is a requirement.
- **Table helpers:** assert table headers and row/cell structure; treat dynamic metrics and visitor counts as time-varying; paginate through all currently rendered page controls and verify content/state changes.
- **Form helpers:** fill named fields, select radio/checkbox/list options, and validate current values; separate browser-native validation from any server response.
- **Interaction utilities:** establish dialog and popup listeners before triggering actions; wait for state/content rather than sleeping; use disposable files for uploads and isolated contexts for external navigation.
- **Locator checks:** assert element count, visibility, and enabled state before interacting; scope repeated buttons such as Submit to their containing form/section.

### Candidate Page Objects / components

| Candidate | Responsibility | Likely component coverage |
|---|---|---|
| `PracticeSitePage` | Shared header, navigation, page title, footer links, and common wait/URL assertions | Home, PlaywrightPractice, Hidden Elements & AJAX |
| `DataEntryForm` | Text fields, gender radios, day checkboxes, country/colors/animals selects, date fields, and submit | Home |
| `UploadFilesWidget` | Single/multiple file selection, upload actions, selected filenames, and observed response | All pages with Upload Files |
| `TablesWidget` | Static/dynamic tables, product rows, pagination controls, and safe dynamic-value assertions | All pages with tables |
